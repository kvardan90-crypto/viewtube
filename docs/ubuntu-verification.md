# Проверка запуска на Ubuntu

13 ноября 2026 года проверили `bash deploy.sh` на Ubuntu 24.04.5 LTS в QEMU под Windows. Первый прогон стартовал с официального образа Canonical без Docker. Скрипт установил Docker, скачал образы PostgreSQL и SeaweedFS и собрал приложение. При первом запуске инициализация прервалась на генерации деморолика из-за лимита FFmpeg в 40 секунд.

В поставку добавили девять готовых MP4. Инициализация ставит их в обычную очередь без генерации файлов во время запуска. Увеличили время ожидания готовности сервисов после того, как эмулируемая ВМ не успела выполнить проверку API за 12 секунд.

На той же ВМ повторный запуск исправленной версии завершился успешно. В нём использовались Docker, кэш сборки и тома, созданные на предыдущих попытках. PostgreSQL, SeaweedFS, worker и API запустились, а `GET /health` вернул `{"ok":true}`.

Последующий сквозной тест на Ubuntu завершился по таймауту. Такой же сценарий ранее прошёл с PostgreSQL и SeaweedFS под Windows. После правок также прошли шесть локальных автотестов. Непрерывный прогон исправленной версии с нового образа без Docker и сквозной сценарий на Ubuntu остаются неподтверждёнными.
