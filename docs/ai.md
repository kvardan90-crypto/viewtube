# Материалы работы с ИИ

Проект создан в чате Codex. Правила разработки, добавленные в проект, находятся в [AGENTS.md](../AGENTS.md). Они применяются к доработкам и проверкам проекта. Отдельные агенты и MCP-сервисы для запуска приложения не нужны.

Разработка шла по частям: API и хранение, интерфейс, затем развёртывание и проверка. Обложки демороликов сгенерированы в ImageGen одним листом 3 × 3. Скрипт наполнения создаёт из его ячеек короткие видео и отправляет их в обычную очередь обработки.

В поставочном ZIP файл `codex-chat.jsonl` содержит видимые сообщения этого чата в исходных записях JSONL Codex. Это выборка на момент сборки архива. Для проверки требования о полном нативном экспорте потребуется отдельная выгрузка со стороны владельца чата.
