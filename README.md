# ViewTube

Видеоплатформа на FastAPI, PostgreSQL, SeaweedFS (S3) и FFmpeg. Интерфейс на HTML, CSS и JavaScript открывается с того же адреса, что и API.

## Запуск на Ubuntu

Распакуйте архив, откройте каталог проекта и выполните на чистой Ubuntu 24.04 LTS:

```bash
bash deploy.sh
```

Нужны интернет для загрузки пакетов и образов и права sudo для установки Docker. Скрипт создаёт `.env` со случайными паролями, поднимает контейнеры, инициализирует схему и загружает девять демороликов. FFmpeg обрабатывает их в фоне. Карточки появляются в ленте по мере готовности.

- Интерфейс: `http://127.0.0.1:8000`
- Swagger: `http://127.0.0.1:8000/docs`
- Проверка процесса API и соединения с БД: `http://127.0.0.1:8000/health`

Если Ubuntu находится на удалённой ВМ, откройте SSH-туннель командой `ssh -L 8000:127.0.0.1:8000 user@vm`. Для другого порта задайте `PORT` в `.env` и повторите запуск.

| Учётная запись | Роль | Пароль в `.env` |
| --- | --- | --- |
| `demo_viewer` | Пользователь | `DEMO_PASSWORD` |
| `demo_mod` | Модератор | `MODERATOR_PASSWORD` |
| `admin` | Администратор | `ADMIN_PASSWORD` |

Демо-авторы используют `DEMO_PASSWORD`. Пароли из `.env` применяются при первом создании соответствующих записей. Для повторного наполнения используйте `sudo docker compose run --rm bootstrap`. Существующие демозаписи сохраняются. Для логов используйте `sudo docker compose logs -f api worker`. Команда `sudo docker compose down` останавливает сервисы с сохранением томов.

## Проверка вручную

1. Зарегистрируйтесь и нажмите «Создать». Загрузите MP4, MOV, MKV, WebM или другой поддерживаемый файл до 256 МБ и одного часа. Страница ролика покажет очередь и автоматически обновится после обработки.
2. Запустите видео, поставьте лайк, напишите комментарий. Откройте главную и найдите ролик по названию.
3. Для приватного ролика раскройте «Управление видео» и выдайте доступ второму пользователю по имени. Второй пользователь откроет ролик по ссылке или на канале автора. После отзыва доступа следующая выдача медиаданных вернёт 404.
4. Подпишитесь на чужой канал. Его публичные ролики появятся в ленте «Подписки». Владелец канала может создать плейлист и добавить ролик через «Управление видео».
5. Отправьте жалобу на чужой публичный ролик. Войдите как `demo_mod`, откройте «Модерация» и скройте ролик. У зрителей исчезнут карточка и доступ по прямой ссылке. Там же можно восстановить ролик.
6. Войдите как `admin` и откройте «Роли пользователей», чтобы назначить роль существующему аккаунту.

Деморолики представляют собой шестисекундные анимированные фрагменты AI-иллюстрации. Для проверки полноценной загрузки используйте свой видеофайл.

## Автотесты

Установите Python 3.13+ и FFmpeg с `libx264`. Команды из корня репозитория:

```bash
python -m pip install -r requirements-test.txt
python -m pytest -q
```

Тесты поднимают временную SQLite, файловое хранилище и запускают реальный FFmpeg. Покрытие включает регистрацию, загрузку и обработку, поиск, Range/HEAD, лайки и комментарии, подписки, выдачу и отзыв приватного доступа, модерацию, смену ролей и ошибку обработки. Для проверки PostgreSQL и S3 на Ubuntu используйте сценарий выше.
