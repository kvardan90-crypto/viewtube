# Регрессия ответов агента ревьюера

В `cases.json` пять промптов. Для каждого записаны инвариант ответа, регулярное выражение и зафиксированный эталон. Эталоны заданы вручную. Первый прогон настоящего ревьюера может отличаться от них.

Передайте каждый `prompt` ревьюеру в отдельном диалоге с одинаковыми системными правилами и `AGENTS.md`. Сохраните ответы в UTF-8 JSON-объект, где ключ — `id` кейса, а значение — полный текст ответа без ручного редактирования. Запустите из корня проекта:

```bash
python tests/reviewer/check.py answers.json
```

Любое отличие от эталона возвращает код 1 и печатает unified diff. Несовпадение с регулярным выражением дополнительно указывает, какой инвариант нарушен. Сравниваются и пробелы, и завершающие переводы строк. Для проверки ограничения «только рекомендации» запускайте ревьюера с правами чтения. Регулярное выражение проверяет текст ответа, а права доступа ограничивают действия.
